# سیستم مدیریت بانک

پروژه پایانی برنامه نویسی با پایتون مجتمع فنی
این پروژه با رویکرد برنامه‌نویسی شیءگرا (OOP) و معماری **MVC** سازمان‌دهی شده است.

## قابلیت‌ها

### مدیریت مشتریان
- ثبت مشتری جدید
- ویرایش اطلاعات مشتری
- حذف مشتری
- جستجوی مشتری بر اساس نام یا شناسه
- نمایش فهرست مشتریان
- اعتبارسنجی نام، آدرس، تاریخ تولد و رمز عبور

### مدیریت حساب‌های بانکی
- ایجاد و حذف حساب بانکی
- جستجو و نمایش حساب‌ها
- پشتیبانی از سه نوع حساب:
  - حساب جاری (`CheckingAccount`)
  - حساب پس‌انداز (`SavingAccount`)
  - حساب کارتی (`CardAccount`)
- جلوگیری از ثبت شماره حساب و شماره کارت تکراری
- محدودیت حداکثر دو حساب برای هر مشتری

### مدیریت تراکنش‌ها
- واریز وجه
- برداشت وجه
- بررسی مالکیت حساب و اطلاعات ورود مشتری
- بررسی رمز کارت برای حساب‌های کارتی
- جلوگیری از برداشت بیش از موجودی
- ثبت مبلغ، تاریخ و ساعت تراکنش
- نمایش تاریخچه تراکنش‌ها به تفکیک حساب یا به‌صورت کلی

## فناوری‌ها و ابزارهای استفاده‌شده

- **Python** – زبان برنامه‌نویسی پروژه
- **Tkinter** – طراحی رابط گرافیکی
- **Pickle** – ذخیره‌سازی و بازیابی اطلاعات به‌صورت محلی
- **Decimal** – انجام محاسبات مربوط به مبالغ مالی
- **Regular Expressions (Regex)** – اعتبارسنجی برخی ورودی‌ها
- **Object-Oriented Programming (OOP)** – طراحی کلاس‌ها و استفاده از وراثت
- **MVC** – جداسازی مدل، رابط کاربری و کنترل‌کننده‌ها

## معماری برنامه

پروژه از الگوی **MVC** پیروی می‌کند:

- **Model:** شامل کلاس‌های مشتری، حساب، انواع حساب، تراکنش و توابع اعتبارسنجی است.
- **View:** پنجره‌ها و فرم‌های گرافیکی برنامه را با Tkinter نمایش می‌دهد.
- **Controller:** عملیات مربوط به ثبت، ویرایش، حذف، جستجو و مدیریت تراکنش‌ها را انجام می‌دهد.
